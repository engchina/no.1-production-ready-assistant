層ファイル役割例
TIER 1
primitives		tokens/palette.css生の色。テーマを持たない。コンポーネントから参照禁止。ランプ上の位置だけが意味を持つ。--neutral-200
--blue-500
TIER 2
semantic		tokens/colors.css役割で命名。light-dark() により 1 宣言で両テーマを解決。ここだけを参照する。--color-surface
--color-border-control
TIER 2.5
scopes		tokens/colors.css面コンテキスト。color-scheme ごと差し替えるので、内側のコンポーネントは無改造で成立する。[data-surface="inverted"]
[data-surface="code"]
TIER 3
component		components/components.css状態（hover / focus / disabled）。TIER 2 のみ参照。.pr-button--secondary

テーマ切替は color-scheme 一本：<html> = ライト（既定）/ data-theme="dark" = ダーク / data-theme="auto" = OS 追従。既存 3 アプリの class="light" / class="dark" も旧 API として効きます。.dark に全値を手書き複製する運用は廃止しました。
