# 出張旅費規程
## 1. 国内出張
国内出張は、所属長が出張の目的と日程と費用の見込みを確かめて命じる。出張を命じられた社員は、出発の3営業日前までに出張の申請を旅費のシステムで行い、交通の手段と宿泊の有無を入力する。交通の手段は、目的地までの最も経済的な経路を原則とし、新幹線は片道の距離が100キロを超えるときに使える。航空機は、片道の距離が500キロを超えるときか、所属長が時間の短縮のために必要と認めたときに使える。宿泊を伴う出張の宿泊費は、実費を支給し、1泊あたりの上限は東京と大阪では14,000円、そのほかの地域では11,000円とする。日当は1日あたり2,000円を支給し、日帰りで片道の距離が50キロに満たない出張には支給しない。出張の途中で私用の日程を加えたときは、私用の分の交通費と宿泊費は社員が負担する。出張から戻った社員は、帰着の日から5営業日以内に出張の報告と精算を行い、領収書の画像を旅費のシステムに登録する。
## 2. 海外出張
海外出張は、事業部長が命じる。出張を命じられた社員は、出発の2週間前までに海外出張の申請を行い、渡航先の安全の情報を人事部の安全の担当者と確認する。航空機の座席は、飛行の時間が8時間を超えるときに限り、上位の座席を使える。宿泊費は実費を支給し、1泊あたりの上限は渡航先の地域ごとに旅費の別表で定める。日当は1日あたり6,000円を支給する。渡航先の国が出す危険の情報が上がったときは、人事部の安全の担当者の指示で出張を中止するか、予定を早めて帰国する。海外出張の保険は会社が契約し、出張の期間の全体を補償する。帰国の後は、帰着の日から10営業日以内に精算を行い、為替の換算は出発の日の会社の定める換算の率で行う。
