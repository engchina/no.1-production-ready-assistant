# 研修制度
## 1. 目的
この制度は、社員の能力の開発のための研修の種類と受講の方法を定める。
## 2. 研修の種類
新任管理職研修は、新たに課長に任命された社員が受ける。受講の期限は、任命の日から6か月以内とする。研修は、労務の管理と評価の面談と予算の管理の3つの科目で構成し、各科目は1日の集合研修で行う。講師は外部の研修会社の講師が務める。修了の条件は、3つの科目の出席と、評価の面談の演習の報告書の提出である。報告書は研修の最終日から2週間以内に人事部へ提出する。修了の後、受講者は上司と面談し、研修で学んだことを職場でどう使うかを話し合う。研修の費用は会社が負担し、受講の時間は勤務の時間として扱う。やむを得ない理由で受講できないときは、次の回の研修に振り替える。振替は1回までとする。研修の内容は、毎年度の始めに人事部が見直し、見直しの結果を社内のポータルに掲載する。受講者の意見は、研修の後のアンケートで集める。新任管理職研修の評価の面談の演習では、受講者が上司と部下の役を交互に演じ、講師が面談の進め方について助言する。予算の管理の科目では、部署の年間の予算の作り方と、予算と実績の差の説明の仕方を学ぶ。労務の管理の科目では、時間外労働の管理と休暇の取得の促し方と、ハラスメントの相談を受けたときの対応を学ぶ。研修の資料は、研修の1週間前に社内のポータルで公開する。受講者は、研修の前に資料を読み、職場の課題を1つ書いて持参する。研修の会場は本社ビルの研修室とし、遠方の拠点の受講者は交通費と宿泊費を会社が負担する。研修の日程は、人事部が年度の始めに4回分を決め、受講者は都合の良い回を選ぶ。新任管理職研修を修了した社員には、修了の証を人事部が発行し、人事の記録に残す。修了した社員は、翌年度に新任管理職研修の相談役として、受講者の質問に答える役を務めることがある。研修の評価のアンケートの結果は、講師と人事部が読み、次の回の研修の進め方に生かす。研修の受講は、管理職の昇格の審査の条件の1つとする。新任管理職研修の受講者が研修の途中で異動したときは、異動の先の所属長と相談して、残りの科目の受講の時期を決める。受講者の名簿は人事部が管理し、修了の状況を所属長へ毎月知らせる。
次に、中途入社者研修について定める。中途入社者研修は、前の職場の経験を持つ社員がサンプル社の仕事の進め方を早く身に付けるための研修である。
受講の期限は、入社の日から3か月以内とする。講師は人事部の担当者が務める。修了の条件は、eラーニングの5つの講座の修了である。講座は、社内のシステムの使い方と情報セキュリティと経費の精算と品質の管理と社内の組織の5つである。
