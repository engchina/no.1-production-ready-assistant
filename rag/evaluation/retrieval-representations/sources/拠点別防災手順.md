# 拠点別防災手順
## 1. 目的
この手順は、地震と火災のときの拠点ごとの避難と安否の確認の方法を定める。
## 2. 避難
本社ビルでは、地震の揺れが収まった後に、各階の防災の担当者の指示で階段から避難する。エレベーターは使わない。集合場所は本社ビルの南側の広場とする。集合場所では、部署ごとに点呼をとり、人数を防災センターへ報告する。けが人がいるときは、1階の救護所へ運ぶ。非常用の備蓄は本社ビルの各階の防災倉庫にあり、3日分の水と食料を置いている。帰宅が難しい社員は、本社ビルの会議室にとどまる。安否の報告は、社内の安否確認のシステムで行い、システムが使えないときは所属長へ電話で伝える。火災のときは、煙を避けて姿勢を低くし、防火扉を閉めながら避難する。避難の訓練は年に2回行い、訓練の結果を総務部が記録する。訓練に参加できなかった社員は、翌月の訓練に参加する。来客がいるときは、応対した社員が来客を集合場所まで案内する。本社ビルの防災の担当者は、各階に2人ずつ置き、毎年4月に総務部が指名する。担当者は、月に1回、消火器と非常口の表示と防災倉庫の中身を点検し、点検の結果を総務部へ報告する。本社ビルの防災センターは1階の受付の奥にあり、地震のときは館内の放送で避難の指示を出す。放送が聞こえないときは、各階の担当者が拡声器で指示を伝える。本社ビルにとどまる社員の名簿は、防災センターが作り、家族からの問い合わせに答えるために使う。夜間や休日に地震が起きたときは、出社せずに自宅の安全を確保し、安否確認のシステムで報告する。本社ビルの周辺の道路が通れないときの帰宅の経路は、総務部が社内のポータルに掲載する。本社ビルの防災倉庫の鍵は、各階の防災の担当者と防災センターが持つ。備蓄の水と食料は、賞味期限の半年前に入れ替え、入れ替えた備蓄は社員に配る。本社ビルの消防の設備の点検は、ビルの設備の業者が年に2回行い、点検の日には火災報知器の試験の音が鳴ることを事前に社内へ知らせる。地震の後に本社ビルの建物の安全を確かめるまでは、ビルの中に戻らない。本社ビルで火災の報知器が鳴ったときは、火元の階の担当者が火元を確かめ、防災センターへ内線で伝える。初期の消火ができないと判断したときは、消火を止めて避難する。
大阪支店については、建物の構造が本社ビルと違うため、次のとおり扱う。大阪支店は商業ビルの5階にあり、ビルの管理会社の指示に従う。
集合場所は、ビルの北側の公園とする。非常用の備蓄は地下1階の倉庫にあり、1日分の水を置いている。安否の報告は、支店長へ電話で行う。支店長に連絡できないときは、本社の総務部へ連絡する。
