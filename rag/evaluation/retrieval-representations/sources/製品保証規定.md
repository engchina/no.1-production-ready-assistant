# 製品保証規定
## 1. 目的
この規定は、サンプル社が販売する家電製品の保証の内容を定める。
## 2. 保証の内容
空気清浄機 AP-200 の保証期間は、購入日から1年とする。保証期間の中に通常の使い方で故障したときは、無償で修理する。修理は、お客様が製品を修理センターへ送付する方法で行い、送料は会社が負担する。フィルターは消耗品であり、保証の対象外とする。落下や水没による故障、改造による故障も保証の対象外とする。修理の受付には、購入日を確かめられる領収書か保証書が要る。保証書を無くしたときは、購入した店舗の購入記録で代えられる。修理の期間は、修理センターに製品が届いてから10営業日を目安とする。修理の期間が10営業日を超えるときは、代替機を貸し出す。代替機の送料も会社が負担する。保証の期間を過ぎた後の修理は有償とし、見積もりの金額をお客様が承諾してから修理する。見積もりの承諾が無いまま30日を過ぎたときは、製品を返送する。AP-200 の修理の受付は、ウェブの申込みの画面か電話で行う。申込みの画面では、製品の型番と製造番号と故障の症状を入力する。製造番号は、本体の背面の銘板に書かれている。修理センターは、製品が届いた日にお客様へ受付の完了をメールで知らせる。修理の内容は、修理の報告書として製品と一緒に返送する。AP-200 の同じ箇所の故障が修理の後3か月の中に再び起きたときは、保証の期間を過ぎていても無償で修理する。販売店で購入した製品も、同じ方法で修理を受け付ける。法人の顧客がまとめて購入した製品は、法人の窓口で修理を受け付ける。海外で購入した製品は、保証の対象外とする。修理の際にお客様の設定は初期の状態に戻ることがある。AP-200 の本体の色の違いや外装の小さな傷は、性能に影響しないため保証の対象外とする。AP-200 のセンサーの誤作動が疑われるときは、まず取扱説明書の手順でセンサーの掃除を行い、それでも直らないときに修理を申し込む。修理の申込みの後、お客様の都合で修理を取り消したときは、送料をお客様が負担する。修理センターの受付の時間は、平日の9時から18時までとする。
次に、加湿器 HM-50 の保証の内容を定める。HM-50 は水を扱う製品のため、空気清浄機と扱いの違う点がある。保証の申し込みはお客様相談窓口で受け付ける。
保証期間は、購入日から2年とする。修理は、技術者がお客様の自宅を訪ねる出張修理で行う。出張の費用は保証期間の中なら無償とする。タンクのひび割れは、使い方による損傷として保証の対象外とする。水あかによる故障も、手入れの不足として保証の対象外とする。部品の交換が必要なときは、出張の日から7営業日の中に交換の部品を持って再訪する。
