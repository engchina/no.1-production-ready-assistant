# RAG のデータベース設定を使ってみる

## はじめに

RAG は、文書の索引や会話などのデータを Oracle AI Database に保存します。**システム設定 → データベース**では、その接続に使うユーザー、パスワード、DSN を確認・設定できます。

この記事では、画面の読み方、DB 接続テスト、入力エラーの確認を説明します。**DSN** は接続先を指定する情報で、`host:port/service_name` の形式か接続記述子で入力します。

## 前提条件

- RAG にログインでき、「システム設定」の「データベース」を開ける権限があること。
- 接続テストには、利用可能なデータベースと、接続ユーザー・パスワード・DSN が必要です。**ADB** は Oracle Autonomous AI Database の略称です。
- 保存を練習する場合は、独立した検証環境を用意してください。データベース設定は RAG・NL2SQL・Agent の共通設定です。

環境のアドレスは、環境管理者から案内された `<環境URL>/rag/` を使います。認証情報を記事やスクリーンショットに転記しないでください。

## 今回使うサンプル

| ファイル | 用途 |
|---|---|
| [入力確認用.json](samples/入力確認用.json) | 空白のユーザー名による必須入力エラーと、架空の記入例を説明する日本語のデータ |

サンプルは新しく作成した合成データです。実在する接続先・パスワード・鍵・証明書を含みません。添付サンプルだけで接続成功を再現することはできません。

## 操作手順

### 1. データベース設定を開く

1. 左のナビゲーションで **システム設定** を開きます。
2. **データベース** を選びます。
3. 見出し **データベース設定** と、接続設定のカード **データベース設定** が表示されることを確かめます。DB の起動・停止と状態の表示はこの画面にはありません（#10。ADB Free コンテナは `docker start` / `docker stop` で操作します）。

### 2. 接続情報の項目を確認する

**データベース設定** のカードで、次の項目を確認します。

| 項目 | 入力・確認する内容 |
|---|---|
| データベースユーザー | 管理者が用意したアプリ用ユーザー。架空の記入例は `SAMPLE_APP` |
| データベースパスワード | 新しく設定・更新する場合に入力。保存済みなら空欄で既存値を保持 |
| DSN | `host:port/service_name` か接続記述子。架空の記入例は `sample-db.example.test:1521/sample_service` |

**保存済みパスワードを削除する**は、値を保持したい場合はオンにしません。

### 3. DB 接続テストを実行する

1. 既存の設定を確認する場合は、入力値を変えずに **DB接続テスト** を押します。
2. 処理が終わるまで待ちます。
3. **Oracle AI Database への接続に成功しました。** と表示されることを確かめます。

所要時間は環境や実行ごとに変わります。

このテストは**現在の入力欄の値**を使います。パスワードが空欄の場合は保存済みの値を使い、接続候補を保存せずに確認できます。

DB 接続テストは接続と最小限の読み取りであり、設定保存や表の初期化は行いません。成功しても、文書の取込やモデル呼び出しまで成功するとは限りません。

### 4. 合成データで入力エラーを確かめる

この手順は、入力ミスを学ぶための例です。確認後はページを再読み込みし、未保存の入力を破棄します。

1. [入力確認用.json](samples/入力確認用.json)を開きます。
2. **データベースユーザー** を半角スペース3文字に置き換えます。
3. **DB接続テスト** を押します。
4. **データベースユーザーを入力してください。** と表示されることを確認します。この状態では DB 接続テストは送信されません。
5. ページを再読み込みします。離脱確認が表示された場合は、検証用の入力を破棄します。

### 5. 設定を変更する場合の保存手順を知る

1. 独立した検証環境で、管理者が用意したユーザー・パスワードを入力します。
2. **DSN** に接続先を入力します。
3. **DB接続テスト** で接続を確認します。
4. **DB設定を保存** を押します。
5. **保存しました** の表示を確認し、再表示後もユーザー・DSN とパスワードの保存状態が期待どおりであることを確認します。

## 結果の確認

| 確認対象 | 成功の目印 |
|---|---|
| 画面表示 | 見出し「データベース設定」 |
| DB への接続 | 「Oracle AI Database への接続に成功しました。」 |
| 必須入力 | 空白だけのユーザーに必須入力エラー |
| 設定の保存 | 「保存しました」と再表示後の保持 |

## よくあるつまずきと対処

| 状況 | 対処・注意点 |
|---|---|
| ユーザーを入力したつもりでもエラーになる | 半角スペースだけでは受け付けない。管理者から案内されたユーザー名を入力する |
| 保存済みなのにパスワード欄が空に見える | 保存済みの表示を確認する。更新しない場合は空欄で既存値を保持する |
| DSN の形式のエラーになる | 別名だけ（`[A-Za-z0-9_.-]` の文字だけ）は使えない。`host:port/service_name` か接続記述子で入力する |
| 接続テストが失敗する | 表示された案内を確認し、DB の起動状態、ユーザー・パスワード、DSN の host・port・サービス名、ネットワークを管理者と確認する |

## まとめ

データベース設定では、DB 接続情報を確認し、**DB接続テスト**で現在の入力値による接続を確かめられます。保存済みパスワードは、更新しない場合は空欄で保持します。

確認範囲と根拠は[検証記録](検証記録.md)にまとめています。
