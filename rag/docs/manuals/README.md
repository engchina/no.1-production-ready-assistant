# RAG の操作マニュアル

初めて使う利用者向けに、実画面の確認範囲を明記した操作記事をまとめます。

| 機能 | 記事 |
|---|---|
| OCI 認証 | [OCI 認証設定を使ってみる](oci-authentication/README.md) |
| アップロード保存先 | [アップロード保存先を使ってみる](upload-storage/README.md) |
| モデル | [モデル設定を使ってみる](model-settings/README.md) |

各記事に、日本語の合成サンプル、機密情報を除いた注釈付き実画面、検証記録をまとめています。実操作で確認した範囲、実装を照合した説明、未実施の操作を区別しています。

[マニュアル作成用プロンプト](../../../docs/manuals/作成用プロンプト.md)には、日本語の資料・合成データ、機密情報の保護、枠・丸・番号・矢印を含む画面注釈の要件を記載しています。
