- 確認日：2026年10月28日（日本時間）。

## 実操作で確認した範囲

| 操作 | 結果 |
|---|---|
| ログイン、モデル設定画面表示 | 見出しと3区画（OCI Enterprise AI、登録モデル、OCI Generative AI）を確認 |
| 保存済み設定の閲覧 | 接続タブと項目、保存済み API key の状態、登録モデル、既定モデル、埋め込み・リランク欄を確認。実値は公開資料へ転記していない |
| 未保存行の追加 | 「追加」で6行目を作り、合成モデル ID、合成表示名、プライマリ接続、low、入力4096、出力2048、画像入力オフを表示 |
| 1440px幅の確認 | 合成行を単独撮影。接続区画と Generative AI 区画は設定値などを撮影時に不透明マスク |
| 375px幅の確認 | 合成行が縦に並び、値・テストボタンを確認。documentElement.scrollWidth > innerWidth は false |
| 埋め込みモデルのテスト | 既存の埋め込みモデル ID を変更せず、画面の「テスト」で実サービスを呼出し。「1536 次元ベクトルを取得しました。」を含む成功文の存在1件、失敗文の存在0件を確認 |
| 合成入力の破棄 | 再読み込み後、値が「架空」で始まる入力欄0件、設定フォーム3区画を確認。保存は行っていない |

テスト時にシステムが送る入力は、共通実装の日本語の合成短文「モデル接続テスト」。既存文書・検索結果・履歴は使用していない。モデルテスト API は入力中の設定から一時候補を生成し、設定ストアの保存処理を呼ばないことを照合した。合成の未保存行はテスト時の画面に存在したが、呼び出した対象は保存済みの埋め込みモデルであり、架空モデルの実行はしていない。

## 未実施と制約

- 接続情報・API key の変更・削除と保存。
- 接続の追加・削除、既定モデルの変更。
- 登録モデルの保存確定・削除確定。
- Generative AI 設定の変更と保存。
- 回答生成、画像対応、リランクのテスト。
- 入力エラー、保存競合、モデル接続失敗の再現。
- 文書取込、検索、回答生成の一連の動作。

不正な上限値を入れて「保存」を押す入力検証は、実行前に自動承認で拒否された。理由は「既存設定を変更し得る書込み操作」「非GET遮断の確実性が未確認」である。このコマンドは全体が未実行であり、保存操作を再試行していない。実際に入力して撮影した値は入力4096・出力2048の有効範囲である。

また、既定モデル欄のボタンのみをマスクして撮影する案と、テスト結果欄の全文読取は、設定値や診断情報が残り得るとして自動承認で拒否された。前者の画像は作成せず、後者は全文を取得せず成功文の存在のみで確認した。最終のテスト画像は入力欄・結果文・詳細領域をすべて黒塗りにして撮影した。

## 実装の根拠

以下のファイルを照合した。保存通知や未実施の操作は実測結果として扱っていない。

- `platform/packages/system-settings/src/model/ModelSettingsPage.tsx`：区画別保存、追加行、未保存設定でのテスト、既定モデル、上限検証。
- `platform/packages/system-settings/src/model/messages.ts`：表示名、補足、通知、エラーメッセージ。
- `platform/packages/system-settings/src/model/defaultModels.ts`、`connections.ts`：既定モデル候補と接続の検証。
- `platform/packages/system_settings_backend/src/pr_system_settings/model.py`：一時テスト設定、保存処理との分離、1536次元の成功文。
- `platform/packages/system_settings_backend/src/pr_system_settings/model_test_input.py`：共通の日本語テスト入力。
- `rag/backend/app/api/routes/settings.py`：埋め込みテストの実サービス呼出しと、文書を使わない入力。
- `rag/backend/app/security/permissions.py`：`menu.settings_model` と対象APIの権限。
