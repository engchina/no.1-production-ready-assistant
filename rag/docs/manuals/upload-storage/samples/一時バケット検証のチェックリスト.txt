架空サンプル：一時バケットによる接続確認チェックリスト

実際の認証情報、OCID、namespace、バケット名は記入しないでください。
山括弧の項目は説明用の目印です。

準備：
[ ] 環境管理者が、RAG に設定済みの OCI 認証を確認した。
[ ] <コンパートメント_OCID> 内に検証専用の非公開バケットを作成した。
[ ] バージョン管理なし、一意な検証用の名前、検証用途を示すタグを使用した。
[ ] <検証用バケット名> とリージョンを作業者に案内した。

RAG の実画面：
[ ] システム設定 → アップロード保存先を開いた。
[ ] OCI Object Storage を選び、リージョンとnamespaceを確認した。
[ ] <検証用バケット名> を入力し、「接続を確認」を押した。
[ ] OCI 認証の設定、bucket の確認、書込み、読取り、削除の5段階が成功した。
[ ] 成功メッセージを確認した。
[ ] 保存は押さず、未保存の入力を破棄した。

後片付け：
[ ] 検証用バケットにオブジェクトが残っていないことを確認した。
[ ] 今回作成した検証用バケットだけを削除した。
[ ] 削除後にバケットを取得できないことを確認した。
[ ] 元の保存先設定が変わっていないことを確認し、ログアウトした。

このチェックリストは、画面に取り込むファイルではありません。
OCI バケットの作成・削除は、RAG の設定画面の外で行う準備作業です。
