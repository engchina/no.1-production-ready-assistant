# アップロード保存先の記事用サンプル

| ファイル | 用途 | 今回の使用状況 |
|---|---|---|
| [入力例.json](入力例.json) | ローカル保存先の未保存入力の例 | 画面へ手入力して確認。JSONファイルのアップロード機能ではない |
| [架空サンプル_原本保存確認.txt](架空サンプル_原本保存確認.txt) | 保存先の設定後に利用できる合成の原本文書 | 内容を新規作成。文書アップロードと原本保存の実測は未実施 |

## 操作を再現する

1. 「アップロード保存先」を開く。
2. JSON の「ローカル保存先の未保存入力例」を「ローカル保存ディレクトリ」に入力する。これは説明用の架空パスで、ディレクトリの作成・保存は行っていない。
3. 検証用の入力を破棄する。既存の保存先は変更しない。

実環境のパスをサンプルに転記しないでください。

OCI Object Storage の保存先とバケット名の形式確認・一時バケットの接続確認の手順は、#11 で機能を削除したため外しました（#51）。
