# アップロード保存先の記事用サンプル

| ファイル | 用途 | 今回の使用状況 |
|---|---|---|
| [入力例.json](入力例.json) | ローカル保存先と、バケット名の不正形式の例 | 画面へ手入力して確認。JSONファイルのアップロード機能ではない |
| [架空サンプル_原本保存確認.txt](架空サンプル_原本保存確認.txt) | 保存先の設定後に利用できる合成の原本文書 | 内容を新規作成。文書アップロードと原本保存の実測は未実施 |
| [一時バケット検証のチェックリスト.txt](一時バケット検証のチェックリスト.txt) | 準備・接続確認・一時リソース削除の確認表 | 設定済みOCI認証で一時バケットを作り、全5段階の成功後に削除した |

## 操作を再現する

1. 「アップロード保存先」で「ローカルディレクトリ」を選ぶ。
2. JSON の「ローカル保存先の未保存入力例」を入力する。これは説明用の架空パスで、ディレクトリの作成・保存は行っていない。
3. 保存せず「OCI Object Storage」へ切り替える。
4. OCI 認証設定が準備済みの検証環境で、JSON の「バケット名の形式エラー確認用」を入力し「接続を確認」を押す。
5. 「英数字、ハイフン、アンダースコア、ドットで入力してください。」が表示されれば、形式チェックが働いている。
6. 検証用の入力を破棄する。既存の保存先は変更しない。

バケット名の日本語文字列は、入力エラーを学ぶための例です。実際のバケット名は英数字・ハイフン・アンダースコア・ドットで入力します。実環境の名前をサンプルに転記しないでください。

テキストファイルを後からアップロードする場合は、保存先設定が完了した独立した検証環境を用意します。アップロードに伴う文書の作成・解析・索引作成は、今回の記事で確認した範囲に含みません。
