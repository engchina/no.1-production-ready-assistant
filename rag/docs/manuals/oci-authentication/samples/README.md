# OCI 認証設定の記事用サンプル

すべて新しく作成した架空のデータです。既存の顧客・人物・組織・文書・認証情報は使用していません。

| ファイル | 用途 | 今回の確認 |
|---|---|---|
| [入力エラー確認用.json](入力エラー確認用.json) | 画面の3項目へ値を手入力し、形式のエラーを確認する | 実画面で確認。ファイルをアップロードする用途ではない |
| [OCI設定テンプレート.ini](OCI設定テンプレート.ini) | サーバー側 config の項目と画面の対応を理解する | 実装と照合。テンプレートの配置・読込・認証は未実施 |
| [架空サンプル_秘密鍵ではありません.pem](架空サンプル_秘密鍵ではありません.pem) | 拡張子と秘密鍵の内容の違いを理解する、認証不能な例 | 実環境へのアップロードは未実施 |

## 入力エラーを再現する

1. マニュアルの「入力例で形式のチェックを確かめる」を読む。
2. 独立した検証環境で「OCI 認証設定」を開く。
3. JSON の「ユーザー OCID」「テナンシ OCID」「フィンガープリント」を対応する欄へ入力する。
4. 「OCI 設定を保存」を押し、各欄の形式エラーを確認する。これらの値は保存の前に入力検証で止まる。
5. 保存せずにページを再読み込みし、入力例を破棄する。離脱の確認が出た場合は、検証用の入力を破棄する操作を選ぶ。

既存の運用環境で認証設定や秘密鍵を練習用に置き換えないでください。このサンプル一式で OCI への認証成功は再現できません。接続成功の確認には、環境管理者が用意した正しい認証情報と対応する秘密鍵が必要です。
