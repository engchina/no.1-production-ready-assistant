## 未実施の操作と理由

共通の既存設定・秘密鍵への影響を避けるため、正しい値の保存、秘密鍵アップロード・差し替え、Object Storage 設定の保存は実施していません。再表示による保存値の永続化も未確認です。秘密鍵アップロード要求は実行前に自動承認審査で拒否され、送信していません。

サンプルの INI は説明用、PEM は秘密鍵の実体を含まない不正入力用です。これらのファイルのサーバー配置・実環境へのアップロードは未実施です。UI で合成値を入力した JSON の3項目だけを実操作で使用しました。

モデル呼出し・文書取込・バケットへの書込み・失敗するOCI接続・暗号化鍵の拒否は実サービスでは検証していません。独立した環境と専用の認証情報を用意してから追加で確認してください。
