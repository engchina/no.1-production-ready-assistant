# 外観と証明書のマニュアル検証記録

確認日：2026年10月28日（日本時間）。対象は RAG の「システム設定 → 外観と証明書」です。

## 実画面で確認したこと

Playwright の Chromium で実際の環境にログインしました。表示や API 応答をモックに差し替えていません。

| 対象 | 結果 |
|---|---|
| ナビゲーション | 「システム設定」を展開し、「外観と証明書」を選択。対象の見出しを確認 |
| 初期状態 | 「ライト」が選択状態 |
| ダーク | 押した直後に暗い配色になり、`aria-pressed=true` を確認 |
| 再読み込み | 「ダーク」の選択が保持され、HTML に dark クラスが付いた状態を確認 |
| 自動（OS 設定） | ボタンを押し、Playwright の `emulateMedia` で OS の配色条件を dark → light に変更。HTML の dark クラスの付与・解除を確認 |
| ライト | 明るい配色に復帰。最後の再読み込みでもライトの選択を確認 |
| 証明書の取得 | 実際にボタンを押し、ダウンロード成功、`production-ready-root-ca.crt`、1797 bytes を確認 |
| 証明書形式 | `openssl x509 -in <ダウンロードした証明書> -noout -checkend 0` 成功。出力は有効期限内である旨のみ。subject/SAN/フィンガープリント等は公開していない |
| 取り込み案内 | 「端末への取り込み方」を開閉し、OS・ブラウザー別の案内を確認 |
| 幅1440pxと375px | 両方で撮影。375px時の document.clientWidth と scrollWidth はともに375。横方向のはみ出しなし |
| 変更系通信 | テーマ操作・再読み込み・証明書の取得の間、POST / PUT / PATCH / DELETE の要求0件 |
| 終了時 | 開始時のライトに戻し、ログアウト、Cookie削除、ブラウザー内保存データの削除を実施 |

ログイン時の通信とログアウト時の通信は、変更系通信0件の集計対象外です。ブラウザーは専用の新規コンテキストを使用し、既存の利用者のブラウザー設定は操作していません。

## 未実施と制約

- OS の設定画面は操作していない。自動配色はブラウザーに通知する OS 配色条件で確認した。
- Windows・macOS・iPhone / iPad・Android の証明書ストアへの取り込み、および Edge・Chrome・Firefox 等の実ブラウザーで警告が解消することは未確認。操作マニュアルでは画面の案内を開くところまでを実操作として扱った。
- 証明書を配布していない場合の画面は実装だけで確認。実環境では証明書が配布されていた。
- 証明書の生成・変更・アップロード・配備・Nginx の再読込は、この画面の機能ではなく、いずれも実施していない。
- 合成 JSON と TXT は日本語で新規作成した説明用資料。画面にインポートする機能はないため、ファイル自体を読み込む操作は実施していない。合成資料のボタン名・操作順を実画面で使用した。

## 画像と情報の保護

画像は実画面の本文領域だけを直接撮影した。ナビゲーションのアカウント表示、アドレスバー、既存の一覧、実環境URL、証明書の内容は撮影範囲外。機密情報が映らない切り取りによって保護したため、本文の値を塗り替えるマスクは不要だった。

説明箇所に赤枠と番号を追加し、余白を切り取った。UI・値・結果の作り替え、生成画像での代用は行っていない。PNG に可逆の注釈レイヤーや認証情報のテキスト層はない。未加工の画像、実際の証明書、セッション情報は公開成果物へ含めていない。
