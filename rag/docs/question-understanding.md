# プロファイルごとの質問の理解

「プロファイルの知識」の「質問の理解」は、そのプロファイルで受けた質問の対象・条件・種類を読む手がかりを管理する。認可、利用者の同意、資料の事実や未確認の条件を確定する設定ではない。モデルへの指示・索引・取込成果物は変更しない。

## 設定と保存

正本は既存の `SearchAnswerProfileConfig.language_pack`。質問理解専用の別ファイルや既定値の複製は作らない。組み込みの言語資源 → 全体の言語資源 → 指定されたプロファイルの項目、の順に解決する。

| 対象 | 編集する手がかり | 編集しない仕組み |
|---|---|---|
| 質問の目的・経緯・条件 | `question_cues` の検索・回答専用項目 | 認可・安全の判定 |
| 画面名・メニュー経路・項目名 | `inquiry_cues` の画面の接尾辞、括弧、経路の区切り、列の語 | 任意の正規表現 |
| 手順・要否・可否・原因など | `inquiry_cues.decision_words` の固定された種類への対応 | 条件の値の推測 |
| 列挙・網羅・定義 | `enumeration_cues` / `definition_cues` の検索専用項目 | 資料に存在することの判定 |
| ファイル名・エラーコード・日付 | 既存の汎用パーサーで認識しプレビューに表示 | ファイル拡張子・エラーコード・日付の形式を自由入力で置き換えること。取込にも使う数・単位の設定は全体に残す |

- 変更しない項目は最新の全体の値を継承する。
- 一覧は項目単位で**置き換える**。追加したい場合は既存の語を残して追記する。語は正規表現として実行せず、既存のエスケープ済みの組立で扱う。
- 空の一覧 `[]` はその項目の語を使わない。項目の「全体の値に戻す」は上書きを削除し、その時点の全体の値を使う。全体と同じ項目は保存しない。
- API の空の `overrides: {}` はこの面の上書きだけを外す。回答の表示・検査などの他用途の上書きは残す。
- 保存はプロファイルの行をロックして質問理解の項目だけを更新する。古い主フォームで上書きしようとした場合は競合を返す。最新版を取得してから保存し直す。
- 未知の項目・取込用の項目・他用途の項目・型違い・一覧数や語長の超限は 422。未対応の設定を成功扱いしない。

## 実行範囲と診断

`profile_language_scope` が全体の既定へ指定プロファイルの上書きだけを重ね、`ContextVar` に要求の間だけ束ねる。別のプロファイル、並行する要求、入れ子の呼出へ上書きを継承しない。await と `asyncio.to_thread` でも同じ範囲を使い、終了・失敗時に戻す。

| 経路 | 適用する段階 |
|---|---|
| Chat | 会話を踏まえた質問の準備、確認の候補・ガイドの選択、送信後の検索と回答 |
| RAG 検索 | `_resolve_query_context` のルール・ガイドの準備から `RagPipeline.run` の認識・検索・回答まで |
| 公開 MCP | `rag_search` / `rag_retrieve_evidence` が使う共通の検索解決とパイプライン |
| 管理画面のプレビュー | 保存済みと編集中のそれぞれで、原文・認識結果・適用した言語資源の hash を表示。保存・検索・モデル呼出は行わない |

質問の認識結果の `language_pack_hash` が適用した値の版を示す。保存したプロファイル自体の版は既存のプロファイル診断にも残る。取込の metadata hash、ナレッジベース、文書の処理レシピは変えない。

## 知識の表示順

Tab は最初の**主な利用段階**に沿う順。すべてが必ず一度ずつ直列に実行されるという意味ではない。

| 順 | 機能 | 主な分岐・再利用 |
|---|---|---|
| 1 | 登録済みQ&A | 候補を選ぶと通常の確認・資料検索を省略して回答する経路がある |
| 2 | 質問の理解 | 会話文脈を含め、対象・条件・質問の種類を整理する |
| 3 | 用語・同義語 | 質問の表現、ルール・ガイドの照合、検索を補う。認識より先に用語の補完が要る経路でも再利用する |
| 4 | 確認・回答ルール | 用途別に回答前の確認と生成への指示を選ぶ |
| 5 | 業務ガイド | 有効な場合に条件・手順・必要な根拠を選ぶ |
| 6 | ドメインキーワード | 全文検索の語の切出し・登録した語の保護に使う |

表示順のために実行処理を並べ替えない。初期 Tab の登録済みQ&Aと既存の内部 ID は維持する。
